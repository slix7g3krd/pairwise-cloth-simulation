# pairwise-cloth-simulation

旗帜在高风速下穿过旗杆，布料顶点每帧只做一次位置修正，碰撞检测发生在积分之后；结构约束按固定迭代次数，强风下拉伸到两倍长度；风场按世界坐标采样，旗面移动后纹理像在旗上滑动；自碰撞只检测相邻粒子，折叠处两层布互相穿透；固定点约束没按骨骼变换更新，角色跑动时旗杆被拽弯；子步数按帧率固定，低帧率下布料直接穿过栏杆；摩擦系数只作用于切向速度，布料挂在钉子上慢慢滑落；LOD 切换时约束图重建，远处旗帜突然变硬；GPU 端模拟结果回读晚一帧，画面与碰撞体错位；暂停后风速累积，恢复瞬间旗帜炸开。render/cloth_simulation.py 是核心，tests/test_cloth_simulation.py 15个红。要修的是：碰撞在积分前做连续检测；约束按误差自适应迭代；风场转到局部空间；自碰撞用空间哈希全局检测；固定点跟随骨骼；子步按时间固定；摩擦加静摩擦；LOD 继承约束状态；回读加插值延迟；暂停冻结风场。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
